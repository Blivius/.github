# Getting help

- **A question or an idea:** open a Discussion on the project's repository, if it has Discussions
  enabled. Otherwise open an issue.
- **A bug:** open an issue on the project's repository with the version, what you ran, and what
  happened.
- **A security problem:** never in public. See [`SECURITY.md`](SECURITY.md).
- **Anything else:** hello@blivius.com.
